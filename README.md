# KNOWFLOW

### AI-Powered Evidence-Based Knowledge Handover Platform

Knowflow is an AI-powered platform designed to prevent critical project knowledge from being lost when team members leave an organisation or project.

It converts scattered project information into structured, evidence-backed and role-specific handover reports.

## Core Features

- Project and team management
- Role-based access control
- PDF and DOCX document ingestion
- GitHub repository integration
- AI-powered knowledge extraction
- Project-state reconstruction
- Evidence-based handover reports
- Role-specific information filtering
- Manager review and approval
- Secure report sharing and acknowledgement

## Technology Stack

**Frontend:** React.js, TypeScript, Tailwind CSS

**Backend:** Node.js, Express.js, TypeScript

**AI Service:** Python, FastAPI

**Database:** PostgreSQL, pgvector

**AI Processing:** Document parsing, embeddings, retrieval and LLM-based extraction

**Integration:** GitHub API

## Repository Structure

- `frontend/` – User interface

- `ai-service/` – AI processing and knowledge extraction
- `database/` – Database schema and migrations
- `storage/` – Local development file storage
- `docs/` – Technical documentation
